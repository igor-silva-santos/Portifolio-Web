Laboratório · Anime.js v4

Aprendendo Anime.js na prática

Mesma estrutura do laboratório de GSAP: cada bloco isola um conceito, com demo ao vivo, código ao lado e botão "Replay". Anime.js v4 é mais leve e modular — mas a API muda em pontos importantes.

Diferenças que pegam quem vem do GSAP: duração é em milissegundos, não segundos. Não existe gsap.from() separado — usa-se um valor em array [de, para] na própria propriedade. E a biblioteca é ESM-only: sem build tool, carregamos via <script type="module"> importando de um CDN, em vez de um <script src> comum que cria uma variável global.
01 · ANIMATE

animate() — "to" e "from" na mesma função

Só existe animate(). Por padrão ele funciona como o gsap.to() (anima até o valor). Pra imitar o gsap.from(), passa a propriedade como array: [valorInicial, valorFinal].

// estilo "to" — anima ATÉ os valores
animate('#an-to', {
  y: -30,
  rotate: 180,
  duration: 1000, // ms, não segundos!
  ease: 'outQuad'
});

// estilo "from" — array [de, para]
animate('#an-from', {
  y: [-30, 0],
  opacity: [0, 1],
  duration: 1000,
  ease: 'outQuad'
});
02 · TIMELINE

Sequenciamento com createTimeline()

Mesmo conceito do GSAP: uma timeline agrupa animações em sequência via .add(). A sintaxe de overlap ("-=0.3" no GSAP) existe aqui também através do parâmetro de posição, mas não testei todas as variações — vale checar a doc de Time Position antes de usar em produção. Por enquanto: sequência simples.

const tl = createTimeline({ defaults: { duration: 500 } });

tl.add('.tl-card:nth-child(1)', { opacity: 1, y: 0 })
  .add('.tl-card:nth-child(2)', { opacity: 1, y: 0 })
  .add('.tl-card:nth-child(3)', { opacity: 1, y: 0 })
  .add('.tl-card:nth-child(4)', { opacity: 1, y: 0 });

// .label('nome') marca um ponto pra reaproveitar depois
03 · STAGGER

stagger() no delay

Igual ao GSAP: em vez de .stagger-1...stagger-4 manuais no CSS, a função stagger() gera o delay escalonado pra você.

animate('#stagger-grid .box', {
  opacity: 1,
  y: 0,
  duration: 500,
  ease: 'outBack',
  delay: stagger(60) // 60ms entre cada elemento
});
04 · EASING

Nomes de ease diferentes do GSAP

Mesma ideia do GSAP, nomenclatura diferente: aqui é outQuad, outElastic(.8,1.2) em vez de power2.out, elastic.out(1,.4). O padrão é sempre in/out/inOut + nome da curva.

outQuad
outExpo
outBack
outElastic(.8,1.2)
outBounce
// mesma animação, ease diferente:
animate(dot, { left: '90%', duration: 1400, ease: 'outQuad' });
animate(dot, { left: '90%', duration: 1400, ease: 'outBack' });
animate(dot, { left: '90%', duration: 1400, ease: 'outElastic(.8,1.2)' });
animate(dot, { left: '90%', duration: 1400, ease: 'outBounce' });

// veja todas em animejs.com/documentation/easings/built-in-eases
05 · ONSCROLL

Reveal ao rolar (autoplay: onScroll)

Equivalente ao ScrollTrigger do GSAP. Em vez de um parâmetro scrollTrigger, o onScroll() vira o valor de autoplay da própria animação. enter/leave definem os limiares como "posição-do-alvo posição-do-container".

Card 1 — aparece ao entrar na viewport
Card 2 — controlado por onScroll(), não por observer manual
Card 3 — mesmo resultado do js/scroll-reveal.js atual
document.querySelectorAll('.an-reveal').forEach(el => {
  animate(el, {
    opacity: [0, 1],
    y: [40, 0],
    duration: 800,
    autoplay: onScroll({
      container: '#scroll-sim-anime',
      enter: 'top bottom',  // topo do card toca a base do container
      leave: 'bottom top'
    })
  });
});

// se a animação dispara de novo a cada vez que reentra

07 · INTERAÇÃO

Botão magnético com createAnimatable()

Equivalente ao gsap.quickTo(). createAnimatable() cria um objeto que você chama como função — animatable.x(valor) — otimizado pra eventos de alta frequência como mousemove. Aqui os números nas propriedades (x: 400) são a duração em ms, não o valor alvo — o valor alvo entra depois, na chamada.

const btn = document.querySelector('#magnetic-anime');
const animatable = createAnimatable(btn, {
  x: 400, // duração da animação de x, em ms
  y: 400,
  ease: 'out(3)'
});

btn.addEventListener('mousemove', (e) => {
  const r = btn.getBoundingClientRect();
  animatable.x((e.clientX - r.left - r.width/2) * 0.35);
  animatable.y((e.clientY - r.top - r.height/2) * 0.35);
});
btn.addEventListener('mouseleave', () => { animatable.x(0); animatable.y(0); });
