## ✨ Destaques

- 📱 **Mobile Nativo** — Desenvolvido com .NET MAUI para máxima performance.
- 💾 **Persistência Offline** — Banco de dados SQLite integrado para uso sem internet.
- 🏗️ **Arquitetura MVVM** — Separação clara de responsabilidades e código escalável.
- 🚀 **Cross-platform** — Estrutura preparada para Android e iOS.
- 📊 **Gestão de Cargas** — Controle preciso de evolução em cada exercício.

## 💡 Por que este projeto?

O **App Fit** foi criado para demonstrar versatilidade técnica além do ecossistema JavaScript. O objetivo foi enfrentar os desafios de desenvolvimento mobile nativo, como gerenciamento de ciclo de vida do app, banco de dados relacional local (SQLite) e a criação de interfaces que respeitem os padrões de cada sistema operacional.

## 🛠️ Tecnologias

- **C# / .NET MAUI** — Framework principal para desenvolvimento multiplataforma.
- **SQLite** — Persistência de dados relacional e local.
- **MVVM Pattern** — Padrão de arquitetura para desacoplamento de UI e lógica.

## 🚀 Roadmap (Onde este projeto pode chegar)

- [ ] **Integração Health:** Sincronização com Apple Health e Google Fit.
- [ ] **Gamificação:** Sistema de medalhas e recordes pessoais.
- [ ] **Cloud Sync:** Sincronização automática com a nuvem via Firebase ou Azure.
