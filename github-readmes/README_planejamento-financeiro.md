## ✨ Destaques

- 📊 **Visualização Analítica** — Gráficos interativos para entradas e saídas.
- 🧮 **Cálculos em Tempo Real** — Processamento de saldos e metas no front-end.
- 🌐 **Global State** — Gerenciamento de estado centralizado com Context API.
- 🎨 **UI Profissional** — Interface limpa e intuitiva focada em dashboards.
- 📱 **Responsivo** — Controle financeiro disponível em qualquer dispositivo.

## 💡 Por que este projeto?

Este projeto demonstra a capacidade de transformar dados brutos em informações visuais úteis. O desafio técnico residiu na manipulação de estados complexos (várias transações afetando múltiplos saldos) e na integração de bibliotecas de gráficos (Recharts) de forma performática.

## 🛠️ Tecnologias

- **React** — Core do dashboard.
- **TypeScript** — Modelagem dos dados financeiros.
- **Recharts** — Renderização de gráficos de área e pizza.
- **Tailwind CSS** — Layouts de grade (Grid) e flexibilidade.
