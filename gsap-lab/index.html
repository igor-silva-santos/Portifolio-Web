Laboratório · GSAP 3

Aprendendo GSAP na prática

Cada bloco abaixo é um conceito isolado: Tween, Timeline, Stagger, Easing e ScrollTrigger. Role, clique em "Replay" e leia o código ao lado — a ideia é entender antes de levar pro portfólio de verdade.

01 · TWEEN

to / from / fromTo

Um Tween anima propriedades de um alvo ao longo de uma duração. gsap.to() vai do estado atual até o que você define; gsap.from() faz o inverso (útil pra entradas); gsap.fromTo() define os dois pontos.

// gsap.to() — anima ATÉ os valores
gsap.to("#tween-to", {
  y: -30,
  rotation: 180,
  duration: 1,
  ease: "power2.out"
});

// gsap.from() — anima A PARTIR de valores
gsap.from("#tween-from", {
  y: -30,
  opacity: 0,
  duration: 1,
  ease: "power2.out"
});
02 · TIMELINE

Sequenciamento com gsap.timeline()

Uma Timeline agrupa vários tweens em sequência. Por padrão cada .to() encadeado começa quando o anterior termina — e com o parâmetro de posição ("-=0.3") você cria overlaps, igual coreografia.

const tl = gsap.timeline();

tl.to(".tl-card:nth-child(1)", { opacity:1, y:0, duration:.5 })
  .to(".tl-card:nth-child(2)", { opacity:1, y:0, duration:.5 }, "-=0.3")
  .to(".tl-card:nth-child(3)", { opacity:1, y:0, duration:.5 }, "-=0.3")
  .to(".tl-card:nth-child(4)", { opacity:1, y:0, duration:.5 }, "-=0.3");

// "-=0.3" = começa 0.3s ANTES do anterior terminar
03 · STAGGER

Cascata automática em múltiplos elementos

Em vez de escrever um tween pra cada card (como fizemos com .stagger-1, .stagger-2... no CSS do portfólio), o GSAP anima a lista inteira de uma vez e escalona o delay sozinho.

gsap.to("#stagger-grid .box", {
  opacity: 1,
  y: 0,
  duration: .5,
  ease: "back.out(1.7)",
  stagger: 0.06 // 60ms entre cada elemento
});

// stagger também aceita objeto:
// stagger: { each: 0.06, from: "center" }
04 · EASING

A curva importa mais que a duração

O CSS do portfólio usa só ease/linear. GSAP tem uma biblioteca inteira de curvas — o mesmo movimento (mesma distância, mesmo tempo) parece completamente diferente dependendo da ease.

power1.out
power4.out
back.out(2)
elastic.out(1,.4)
bounce.out
// mesma animação, ease diferente:
gsap.to(dot, { x: "90%", duration: 1.4, ease: "power1.out" });
gsap.to(dot, { x: "90%", duration: 1.4, ease: "back.out(2)" });
gsap.to(dot, { x: "90%", duration: 1.4, ease: "elastic.out(1,0.4)" });
gsap.to(dot, { x: "90%", duration: 1.4, ease: "bounce.out" });

// veja todas em gsap.com/docs/v3/Eases
05 · SCROLLTRIGGER

Reveal ao rolar (substitui o IntersectionObserver manual)

O portfólio hoje usa IntersectionObserver + classe .reveal.visible em js/scroll-reveal.js. Com ScrollTrigger o mesmo efeito fica declarativo — role a caixa tracejada abaixo pra ver.

Card 1 — aparece ao entrar na viewport
Card 2 — cada um observa o próprio scroll
Card 3 — sem precisar de observer manual
gsap.utils.toArray(".st-reveal").forEach(el => {
  gsap.from(el, {
    opacity: 0,
    y: 40,
    duration: .8,
    scrollTrigger: {
      trigger: el,
      scroller: "#scroll-sim", // (só necessário pq é uma div com scroll próprio)
      start: "top 85%",
      toggleActions: "play none none none"
    }
  });
});
06 · SCROLLTRIGGER

Scrub — animação amarrada à posição do scroll

Com scrub, a animação não "dispara e toca sozinha" — ela fica presa ao scroll, como uma barra de progresso ou efeito parallax. Role a área abaixo devagar.

↓ role pra baixo
a barra acima segue o scroll 1:1
sem eventos de scroll manuais, sem throttle/debounce
fim
gsap.to("#progress-bar", {
  width: "100%",
  ease: "none", // linear: acompanha o scroll sem suavizar
  scrollTrigger: {
    trigger: ".scrub-inner",
    scroller: "#scrub-area",
    start: "top top",
    end: "bottom bottom",
    scrub: true // gruda no scroll ao invés de "tocar" a animação
  }
});
07 · INTERAÇÃO

Botão magnético com gsap.quickTo()

quickTo() cria uma função reaproveitável otimizada pra eventos de alta frequência (como mousemove) — evita criar um tween novo a cada pixel. Passe o mouse perto do botão.

const btn = document.querySelector("#magnetic");
const xTo = gsap.quickTo(btn, "x", { duration:.4, ease:"power3" });
const yTo = gsap.quickTo(btn, "y", { duration:.4, ease:"power3" });

btn.addEventListener("mousemove", (e) => {
  const r = btn.getBoundingClientRect();
  xTo((e.clientX - r.left - r.width/2) * 0.35);
  yTo((e.clientY - r.top - r.height/2) * 0.35);
});
btn.addEventListener("mouseleave", () => { xTo(0); yTo(0); });
